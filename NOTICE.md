# Provenance

- Active feature baseline: Goose Gadget Kit / Super LiberTEA True First Person 0.5.34, extracted into standalone `goose_true_first_person`. The source's MIT license is included as `LICENSE` (HWG90, 2026).
- The rejected .34 persistent camera pin is removed. The camera uses the accepted post-pin .35-.39 design, including a C port of camera_correction.h; later experimental SDK input normalization is not enabled.
- Candidate revision 0.5.34-hellforge.dev.5 retains dev.4’s native camera/root0, branch5 placement/depth, attachment gates, transition handling and independently qualified outgoing cleanup. It adds generic current-weapon/linked-part visibility protection; no resource whitelist restricts that feature. Installed dev.4 loaded from a cold launch but failed the user’s Nova rendering check despite healthy native attachments. The final dev.5 build and offline checks passed; installation and gameplay/visual acceptance remain pending.
- The model inventory now accepts the engine’s real `World.units` Unit handles, encoded `(UnitRef << 2) | 1`. Earlier tag-zero fake fixtures did not expose the rejected-handle bug. No Lua userdata is fabricated.
- Visibility uses a generation-owned native UnitAPI+0x658 pointer filter for qualified current-gun/linked-Unit whole hides and a per-tick default-pass repair from a pre-copied native per-mesh cache pattern. Shadow suppression remains separate; repaired default visibility is not leased back to hidden on TFP-off. Native per-mesh variants and later owners remain authoritative within the stated ownership checks.
- The original Lua `Unit.set_unit_visibility` wrapper directly calls EXE0x205680 and bypasses the filtered SDK slot. This is not an all-writer interception claim; native render ordering, flicker and performance remain live test requirements. The accompanying original-build ABI report records the known routes and limits.
- Camera/presentation, motion, lens, placement and ownership behavior are ported into C. Original Lua/C++ parity oracles were used only during development and are not shipped as runtime dependencies.
- The C engine SDK bridge is adapted from the local HellForge Photo Mode native backport, with this port's build-specific state admission and lifetime tests. The interface calls the game's own scripting runtime through exported C functions.
- HellForge SDK 16 is a build dependency supplied by the user's HellForge installation. Goose Overlay Host supplies the shared renderer, input and theme; its C client header is included in source. Neither host is bundled in the runtime archive.
- Build 25480438 addresses were checked against captured original game/EXE images; no game binaries or game assets are distributed. The contract JSON files, `profile-evidence.json` and `depth-evidence.json` retain the relevant evidence.
- Fird Person research and the quarantined inline optic-selector hook are excluded from this product.
- Private caller-unwind/phase-binder fixtures are research only and are not linked into the runtime. No raw-look integrator, new input hook, request84 write or native blend-packet modification is included; native sensitivity normalization remains unresolved.
- The production source list has 33 C translation units including visibility_policy; final validation totals and hashes are maintained separately in docs/VALIDATION.json. UI styling and Goose Overlay Host theme tokens are unchanged.
- Scythe, Talon and the active giblett Scope of Authority Nova all remain required live regressions; acceptance must also cover other available weapon classes because the feature is generic, not a three-resource whitelist. Nova's custom entity and Unit resource are distinct; the older goose Scope of Authority source is not proof of the active package's behavior. No Scope of Authority code or assets are redistributed by this mod.
